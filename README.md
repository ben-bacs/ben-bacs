## Engineering Principles

- Treat authorization as a server-side invariant
- Validate data at trust boundaries
- Keep secrets out of repositories and client bundles
- Prefer typed contracts and explicit module boundaries
- Automate linting, testing, builds, and security checks
- Document architecture, operational constraints, and known limitations
